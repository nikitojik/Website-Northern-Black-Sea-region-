# **ПРОЕКТ, ПОСВЯЩЕННЫЙ ИЗУЧЕНИЮ АРХЕОЛОГИИ СЕВЕРНОГО ПРИЧЕРНОМОРЬЯ**

## Техническое задание:
Студентам необходимо создать сайт, посвященный истории и археологии Северного Причерноморья и Крыма, содержащий информацию о регионе и об экспедициях Эрмитажа.

## Задачи:
1. Создать интерактивную карту античных городов Северного Причерноморья и Крыма, отметив на ней города:
Борисфен, Гермонасса, Горгиппия, Калос Лимен, Керкинитида, Киммерик, Китей, Мирмекий, Неаполь Скифский, Никоний, Нимфей, Ольвия, Пантикапей, Танаис, Тира, Тиритака, Фанагория, Феодосия, Херсонес.

Специальными значками отметить:
- самые крупные поселения (Ольвия, Херсонес, Пантикапей, Фанагория);
- памятники, исследованные Эрмитажем (Борисфен, Калос Лимен, Китей, Мирмекий, Нимфей, Ольвия, Феодосия).

2. Составить краткое описание истории городов – наиболее крупных античных центров: Ольвия, Пантикапей, Фанагория, Херсонес. (Объем 1-2 стр. А4 каждое).

3. Создать страницу, посвященную истории античной археологии в России с акцентом на исследованиях античности Северного Причерноморья, в которой обязательно упомянуть, что археология в России началась с изучения памятников античности в Северном Причерноморье; что открытие «русской» античности стало важным этапом для осознания России себя мировой державой и подняло престиж страны и императора Николая I. (Объем 2-3 стр. А4)

4. Создать страницу, посвященную археологическим экспедициям, проводимым Эрмитажем в этом регионе.

Для этого необходимо:

1) Провести исследование темы: узнать, что из современных эрмитажных исследователей какие города копает, с какого года ведутся раскопки

2) Подобрать соответствующие фотографии

3) Написать текст (объем 2-3 стр. А4 по каждой из экспедиций)

### Frontend
Задачей этой части команды было выбрать стэк технологий и написать план реализации своей части, а также сделать примерный дизайн сайта.

#### Стек технологий:
- Фреймворк: Vue.js
- Сборщик: Vite
- Маршрутизация: Vue Router - для создания многостраничной структуры (Карта, История городов, Экспедиции, База артефактов).
- Стейт-менеджер: Pinia — для управления состоянием приложения (например, сохранение выбранных фильтров на карте или в каталоге находок).
- Библиотека для карты: Leaflet (через плагин `vue-leaflet` или чистый JS).
- Взаимодействие с Backend: Axios или нативный Fetch API — для получения данных об артефактах из базы данных, которую напишут бэкендеры.

#### План реализации
**Этап 1**: Проектирование и Дизайн (Figma)
- Разработка UI-кита: типографика (хорошо читаемые шрифты для лонгридов + акцентные для заголовков), цветовая палитра, кнопки, карточки.
- Отрисовка кастомных маркеров для карты
- Прототипирование интерактивной карты (состояния при наведении, клике, всплывающие попапы с краткой инфой).
- Дизайн информационных страниц (История городов, История археологии, Экспедиции Эрмитажа).

**Этап 2**: Инициализация проекта и архитектура (Vue.js)
- Развертывание базового шаблона проекта (Vite + Vue 3)
- Настройка Tailwind CSS и подключение шрифтов/цветов
- Настройка Vue Router и создание базового каркаса страниц (Layout, Header, Footer)
- Настройка Pinia для глобального состояния
- Создание базовых переиспользуемых UI-компонентов (кнопки, модальные окна, карточки)

**Этап 3**: Разработка интерактивной карты
- Интеграция библиотеки Leaflet в проект.
- Подбор и подключение базового слоя карты
- Сбор координат (широта/долгота) для всех 19 городов.
- Вывод маркеров на карту с разделением на 3 типа
- Реализация интерактива: при клике на маркер открывается Tooltip/Popup с кратким описанием и кнопкой «Подробнее» (переход на страницу города).
- Адаптация карты под мобильные устройства (удобный зум и свайп).

**Этап 4**: Верстка контентных страниц
- Верстка раздела «История крупных античных центров» (Ольвия, Пантикапей, Фанагория, Херсонес).
- Верстка страницы «История античной археологии в России».
- Верстка страницы «Экспедиции Эрмитажа» (с интеграцией фотографий и текстов от авторов).
- Настройка типографики для лонгридов, чтобы тексты объемом 2-3 страницы А4 было легко читать.

**Этап 5**: Интеграция с Backend
- Написание сервисов (Axios/Fetch) для запросов к API бэкенда.
- Интеграция реальных данных от бэкенд-команды (замена заглушек/mock-данных на реальные ответы сервера).
